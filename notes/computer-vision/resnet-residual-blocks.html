ResNet: residual blocks

The simple shortcut that made networks with a hundred or more layers trainable.

In short

  • Instead of learning the full mapping \(H(x)\), each block learns only the change: the residual \(F(x) = H(x) - x\).
  • A shortcut adds the input back: \(y = F(x) + x\). It needs no extra weights.
  • With this, deeper is better again: ResNet-152 won ImageNet 2015 with 3.57% top-5 error.

ResNet: các khối residual

Đường tắt đơn giản giúp các mạng hàng trăm lớp trở nên huấn luyện được.

Tóm tắt

  • Thay vì học toàn bộ ánh xạ \(H(x)\), mỗi khối chỉ học phần thay đổi: phần dư (residual) \(F(x) = H(x) - x\).
  • Một shortcut cộng đầu vào trở lại: \(y = F(x) + x\). Nó không cần thêm trọng số nào.
  • Nhờ vậy, sâu hơn lại tốt hơn: ResNet-152 thắng ImageNet 2015 với sai số top-5 là 3.57%.

The residual block

If a layer has nothing useful to add, it only needs to output zero, which is much easier than learning to copy its input.

$$y = \operatorname{ReLU}\big(F(x) + x\big),\qquad F(x) = W_2\,\operatorname{ReLU}(W_1 x)$$
  • The shortcut adds no parameters and almost no computation.
  • When the shape changes (fewer pixels, more channels), a 1 × 1 convolution \(W_s x\) adjusts the shortcut.
  • For 50 or more layers, a bottleneck block (1×1 → 3×3 → 1×1 convolutions) keeps the cost low.

Khối residual

Nếu một lớp không có gì hữu ích để thêm vào, nó chỉ cần cho ra số 0, dễ hơn nhiều so với việc học cách sao chép đầu vào.

$$y = \operatorname{ReLU}\big(F(x) + x\big),\qquad F(x) = W_2\,\operatorname{ReLU}(W_1 x)$$
  • Shortcut thêm không tham số nào và gần như không tốn tính toán.
  • Khi kích thước thay đổi (ít pixel hơn, nhiều kênh hơn), một phép tích chập 1 × 1 \(W_s x\) điều chỉnh shortcut.
  • Với 50 lớp trở lên, khối bottleneck (các phép tích chập 1×1 → 3×3 → 1×1) giữ chi phí thấp.

Results

With shortcuts, deeper networks are simply better.

Kết quả

Có shortcut, mạng sâu hơn đơn giản là tốt hơn.

  • Plain networks got worse from 18 to 34 layers. ResNets got better (27.88% → 25.03% top-1 error).
  • ResNet-152 is still cheaper to run than VGG-19, and an ensemble won ImageNet 2015 with 3.57% top-5 error.
  • The learned features also improved object detection on COCO by 28% (relative).
