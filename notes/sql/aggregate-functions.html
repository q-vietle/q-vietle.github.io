Summarising: COUNT, SUM, AVG, MIN, MAX

Turning many rows into one number, and what happens to NULLs along the way.

In short

  • An aggregate function takes many rows and returns one value.
  • COUNT(*) counts rows. COUNT(column), SUM, AVG, MIN and MAX skip NULLs.
  • WHERE decides which rows go in; the aggregate summarises what is left.

SQL · Phần B · Bài 7/14

Tổng hợp: COUNT, SUM, AVG, MIN, MAX

Biến nhiều hàng thành một con số, và điều gì xảy ra với NULL trên đường đi.

Tóm tắt

  • Một hàm tổng hợp (aggregate function) nhận nhiều hàng và trả về một giá trị.
  • COUNT(*) đếm hàng. COUNT(column), SUM, AVG, MIN và MAX bỏ qua NULL.
  • WHERE quyết định hàng nào đi vào; hàm tổng hợp tóm tắt những gì còn lại.

Many values in, one value out

SELECT COUNT(*)      AS n_orders,
       SUM(amount)   AS revenue,
       AVG(amount)   AS average,
       MAX(amount)   AS biggest
FROM orders
WHERE category = 'Tech';

The Keyboard order has no amount. COUNT(*) still counts it as a row, but SUM and AVG leave it out, as if it were not there.

Nhiều giá trị vào, một giá trị ra

SELECT COUNT(*)      AS n_orders,
       SUM(amount)   AS revenue,
       AVG(amount)   AS average,
       MAX(amount)   AS biggest
FROM orders
WHERE category = 'Tech';

Đơn Keyboard không có amount. COUNT(*) vẫn đếm nó như một hàng, nhưng SUM và AVG bỏ nó ra, như thể nó không tồn tại.

Things to watch

  • AVG skips NULLs, so it is the average of the known values. If a missing amount should count as 0, write AVG(COALESCE(amount, 0)).
  • An empty input gives COUNT = 0 but SUM, AVG, MIN and MAX = NULL.
  • You cannot mix an aggregate with a plain column: SELECT product, SUM(amount) FROM orders is an error in PostgreSQL (which product would it show?). To get one total per product, you need GROUP BY, the next note.

Những điều cần để ý

  • AVG bỏ qua NULL, nên nó là trung bình của các giá trị đã biết. Nếu amount bị thiếu cần tính là 0, hãy viết AVG(COALESCE(amount, 0)).
  • Đầu vào rỗng cho COUNT = 0 nhưng SUM, AVG, MIN và MAX = NULL.
  • Không được trộn hàm tổng hợp với cột thường: SELECT product, SUM(amount) FROM orders là lỗi trong PostgreSQL (nó sẽ hiển thị product nào?). Để có một tổng cho mỗi sản phẩm, bạn cần GROUP BY, ở bài tiếp theo.
