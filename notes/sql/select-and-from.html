Your first query: SELECT and FROM

Asking for columns from a table, renaming them, computing new ones and removing duplicates.

In short

  • A query asks for data. It reads the table and never changes it.
  • SELECT lists the columns you want and FROM names the table. * means every column.
  • You can rename a column with AS, compute new values such as amount * 1.1, and remove duplicate rows with DISTINCT.

Truy vấn đầu tiên: SELECT và FROM

Chọn cột từ một bảng, đổi tên, tính cột mới và loại bỏ trùng lặp.

Tóm tắt

  • Một query (truy vấn) hỏi dữ liệu. Nó đọc bảng và không bao giờ thay đổi bảng.
  • SELECT liệt kê các cột bạn muốn và FROM nêu tên bảng. Dấu * nghĩa là mọi cột.
  • Bạn có thể đổi tên một cột bằng AS, tính giá trị mới như amount * 1.1, và loại bỏ các hàng trùng bằng DISTINCT.

Reading a query

SELECT which columns FROM which table. The answer is a new, temporary table.

SELECT name, city
FROM customers;
  • Keywords (SELECT, FROM) are not case-sensitive: select works too. Writing them in capitals is just a habit that makes queries easier to read.
  • Line breaks and spaces do not matter. The semicolon ends the statement.
  • Text values are written in single quotes, 'Hanoi'. Numbers are written as they are.

Đọc một query

SELECT những cột nào FROM bảng nào. Câu trả lời là một bảng mới, tạm thời.

SELECT name, city
FROM customers;
  • Từ khoá (SELECT, FROM) không phân biệt hoa thường: select cũng được. Viết hoa chỉ là thói quen giúp query dễ đọc hơn.
  • Xuống dòng và khoảng trắng không quan trọng. Dấu chấm phẩy kết thúc câu lệnh.
  • Giá trị văn bản đặt trong dấu nháy đơn, 'Hanoi'. Số thì viết nguyên như vậy.

Computed columns, aliases and DISTINCT

SELECT product,
       amount,
       amount * 1.1 AS amount_with_vat   -- computed for every row
FROM orders;

SELECT DISTINCT city   -- each city once
FROM customers;

A computed column exists only in the result; the table is not changed. AS gives any column a new name in the result. DISTINCT compares whole result rows and keeps one copy of each, so SELECT DISTINCT city lists every city once (NULL included, as one value).

Going further: why experienced people avoid SELECT *

SELECT * is perfect for exploring. In an application it fetches columns nobody uses, and the program can break when someone adds or reorders columns. Listing the columns you need makes the query faster and its intent clear.

Cột tính toán, alias và DISTINCT

SELECT product,
       amount,
       amount * 1.1 AS amount_with_vat   -- tính cho từng hàng
FROM orders;

SELECT DISTINCT city   -- mỗi thành phố một lần
FROM customers;

Cột tính toán chỉ tồn tại trong kết quả; bảng không bị thay đổi. AS đặt cho một cột tên mới trong kết quả. DISTINCT so sánh toàn bộ hàng kết quả và chỉ giữ một bản của mỗi hàng, nên SELECT DISTINCT city liệt kê mỗi thành phố một lần (NULL cũng tính là một giá trị).

Đi sâu hơn: vì sao người có kinh nghiệm tránh SELECT *

SELECT * tuyệt vời để khám phá dữ liệu. Trong ứng dụng, nó lấy cả những cột chẳng ai dùng, và chương trình có thể hỏng khi ai đó thêm hoặc đổi thứ tự cột. Liệt kê các cột cần dùng làm query nhanh hơn và ý định rõ ràng.
